En este proyecto se desarrollo una aplicación web donde los estudiantes encuentran tutores, reservan clases y se comunican con ellos, y donde los tutores publican sus ofertas y administran su horario. El proyecto se desarrolló para el curso de Desarrollo Web (Ingeniería en Sistemas, UMG Sede Naranjo) usando el stack MERN: MongoDB, Express, React y Node.js, con TypeScript básico.
